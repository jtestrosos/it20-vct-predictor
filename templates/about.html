How It Works

This predictor estimates which team is more likely to win a map, based only on the agents each team picked, the map, and who picked the map.

What You Enter

  • Team A and Team B agents: 5 each
  • Map: the map being played
  • Map pick: Team A, Team B, or Decider (the map neither team picked)

The Random Forest

A random forest is a group of many decision trees that each make a guess, then vote. This one uses 300 trees with a max depth of 5, trained on 886 maps from professional VCT matches.

For each matchup, the forest looks at 34 features:

Feature What it Means
Pick advantage +1 if Team A picked the map, -1 if Team B did, 0 if it was the decider
Agent difference For each agent: +1 if only Team A has it, -1 if only Team B has it, 0 otherwise
Map A set of 0/1 flags: 1 for the map being played, 0 for all the others

Keeping it Fair

"Team A" and "Team B" are just labels, but a basic model could learn to favor whichever label happens to win more often. To prevent this, every training example was also added with the teams swapped and the result flipped. When you press Predict, the model checks both orderings and averages them, so swapping the teams always gives exactly the opposite result (if A gets 60%, B gets 40%).

Agent Win-Rate Boost

The forest relies heavily on the map, so after it makes its prediction, a modifier adjusts the result using agent win rates. It averages the smoothed win rate of the five agents each team picked. A team with higher-win-rate agents gets a slight boost. Smoothing keeps agents with few games on a map from skewing the result.

Missing-Role Penalties

After the win-rate boost, role penalties are applied. A team without a certain role is at a disadvantage, and how much depends on whether they're attacking or defending. Each half gets its own multiplier (for example, ×0.75 means a 25% reduction).

Attack Half

Missing Role Penalty Why
Controller ×0.75 (extreme) Pushing sites with no smokes is suicidal against operator crossfires
Duelist ×0.90 (moderate-high) No dive mechanics, so the team stalls at chokepoints
Initiator ×0.80 (extreme) Blind entries into active Sentinel traps
Sentinel ×0.95 (low-moderate) Mostly hurts post-plant holds and flank watch

Defense Half

Missing Role Penalty Why
Controller ×0.85 (high) Can't isolate chokepoints or slow coordinated rushes
Duelist ×0.98 (low) Barely affects defensive site anchoring
Initiator ×0.90 (moderate) Weaker retake info, though audio and anchors help
Sentinel ×0.75 (extreme) No stalling tools while teammates rotate

Because every team plays both sides, the attack and defense multipliers are averaged. That average is then converted into a ratio between Team A and Team B, which adjusts the forest's final probability.

Limitations

The model only sees agent picks, the map, and who picked it. It does not know about player skill, team coordination, recent form, or economy. Its accuracy is about the same as always guessing the more common outcome, so use it to explore how compositions and maps interact, not as a forecast.
